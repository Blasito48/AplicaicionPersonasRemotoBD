Esta es una aplicacion Net Core 10 para WindowsForm desarrollada en C# para el aprendizaje de las clases Connection, Command, DataAdapter y DataTable donde se realiza un CRUD sencilo en una sola Tabla con una Base de Datos SQL Sever hospedada en la Nube (MonsterASP o Soome)

Incluye el uso de las librerías Microsoft.Data.SQLClient y la librería ClosedXML para el manejo de los archivos de Excel.
